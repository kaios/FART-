# Digestion Lab

**Version 0.1.3**

Feed a wireframe body and predict what happens next: **BURP**, **FART**, or **SMOOTH RIDE**.
Written in Python with [pygame-ce](https://pyga.me/). Graphics are drawn in code (no image or font
files). Burps and farts are real recordings (public-domain CC0); the background music is composed
by a script in this repo; other sounds are synthesized.
English and Japanese.

## Download / install

| Platform | File | How |
|---|---|---|
| Windows 10/11 (64-bit) | `DigestionLab-v0.1.3.exe` | Single self-contained file. Double-click to play. |
| Debian 12+ / Ubuntu 23.04+ (amd64) | `digestion-lab_0.1.3_amd64.deb` | `sudo apt install ./digestion-lab_0.1.3_amd64.deb`, then launch **Digestion Lab** from the app menu or run `digestion-lab`. |

**Checking the version**: it's shown in the window title and on the title and settings screens.
`digestion-lab --version` prints it on Linux, `dpkg -s digestion-lab` shows the package version,
and on Windows it's under the .exe's **Properties → Details**.

Japanese text uses fonts already installed on the system (Yu Gothic / Meiryo on Windows;
Noto Sans CJK or similar on Linux, which the .deb recommends).

## How to play

1. Pick a mode and difficulty on the title screen.
2. Choose a food from the menu card. Color-coded particles travel down the esophagus.
   The food you eat is replaced by one you haven't had yet (marked **NEW**), so nothing repeats in
   a Classic game, and the menu always offers at least one food of each kind.
3. Before they arrive, predict **[BURP]**, **[FART]** or **[SMOOTH]**. A correct call is worth +100.

| Food type | Path | Result |
|---|---|---|
| Carbonated (soda, sparkling water, ramune, kombucha) | Stomach fills with expanding bubbles | Cheek puff, then **BURP!** 2 s after arrival |
| Fermentable (beans, broccoli, sweet potato, cabbage, onions) | Skips the stomach via the express lane into the lower intestine | Gas builds, then a screen-shaking **FART!** 4 s after arrival |
| Gentle (white rice, bananas, toast, okayu, udon) | Dissolves cleanly in the stomach | **SMOOTH RIDE!** |

### Sounds

Every gassy food has its own **real recorded** burp or fart: public-domain (CC0) clips from
[Freesound](https://freesound.org), trimmed and level-matched. Recordists are credited in
[digestion_lab/sounds/CREDITS.md](digestion_lab/sounds/CREDITS.md).

| Food | Sound |
|---|---|
| Carbonated Soda | Big, long, loud belch |
| Sparkling Water | Short, crisp burp |
| Ramune | Double burp (two quick belches) |
| Kombucha | Long, deep belch |
| Beans | Classic blast with a rippling tail |
| Broccoli | Short, tight squeaker |
| Sweet Potato | Two-part rattler |
| Cabbage | Long, wet and sputtery |
| Onions | Quiet, airy "silent but deadly" |

Gentle foods make no gas, so they play a soft chime instead. Fizzing, gut rumbles, gulps and UI
sounds are synthesized in code.

### Body

A side-view wireframe of a person: face, ear, ribs, spine and arm, with the digestive tract
inside: esophagus, a J-shaped stomach (with lining folds) that swells with gas, a coiled small
intestine, and a large intestine with its pouch-like segments that glows green as gas builds.

### Levels and music

A new level starts every 2 rounds, up to level 5, with a **LEVEL UP!** banner. Each level has
its own background theme in a different key, faster and busier as you climb (104 → 150 bpm);
the title and results screens have a calmer theme. Turn music off in Settings or with `N`.

**Modes**: **Classic** (8 rounds, max 800) · **Rush** (60 seconds, speed ramps up, streak bonuses
up to +200) · **Endless** (3 lives, a wrong or late call costs one). On Rush and Endless the burp and
fart timeouts shorten as the game speeds up.

**Difficulty**: Easy (slower) · Normal · Hard (faster, particles stay gray until they arrive).

Also: a Food Log of facts for every food you've tasted, 10 achievements, and settings for
language, volume, screen shake and fullscreen. Progress is saved to
`%APPDATA%\DigestionLab\save.json` (Windows) or `~/.local/share/digestion-lab/save.json` (Linux).

**Controls**: mouse, or `1`–`6` pick food · `B` / `F` / `S` predict · `Esc` pause · `M` mute ·
`N` music on/off · `F11` fullscreen.

## Run from source

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m digestion_lab
.venv/bin/python -m unittest discover -s tests   # rules, achievements and simulation timing
```

## Build the binaries

```bash
.venv/bin/pip install -r requirements-build.txt
bash packaging/build_linux.sh           # -> dist/digestion-lab_<version>_amd64.deb
bash packaging/build_windows_wine.sh    # -> dist/windows/DigestionLab-v<version>.exe (from Linux, via Wine)
```

On Windows you can instead run `packaging\build_windows.bat` with Python 3.10+ installed.
Builds of earlier versions are kept in `dist/` next to the new ones.

The music loops in `digestion_lab/music/` are generated by `python3 tools/make_music.py` (needs
numpy, development only; the game and the binaries don't use numpy). Re-run it after changing a
track's tempo, key, chords or drum pattern in that script.

The version comes from one place: `__version__` in `digestion_lab/__init__.py`. The build scripts
read it for the .deb version, the .exe file name, and the Windows version resource
(`packaging/make_version_file.py`).

**Release checklist** (every change): bump the patch version in `digestion_lab/__init__.py`, run the
tests, build both the .deb and the .exe, and update this README's changelog and
[BUGS.md](BUGS.md).

The Wine build downloads the official Python for Windows installer from python.org into a private
Wine prefix under `.build/` on first run (about 400 MB). The Linux binary runs on systems with
glibc 2.36 or newer (the version it was built on); build on an older distro for wider support.

## Project layout

```
digestion_lab/
  app.py           window, main loop, input, game flow
  rules.py         pure game rules: modes, scoring, streaks, speed (unit-tested)
  achievements.py  achievement definitions and checks
  foods.py         foods, categories, line icons, EN/JA names and facts
  sim.py           digestion simulation: particles, bubbles, gas, bursts
  geometry.py      body and digestive-tract paths
  render.py        draws the body and simulation
  ui.py            header, menu card, prediction panel, overlay screens
  i18n.py          English / Japanese strings
  fonts.py         system font lookup, mixed Japanese/Latin rendering
  audio.py         loads the recorded burps/farts, synthesizes the other effects
  sounds/          recorded CC0 burp and fart clips (WAV) + CREDITS.md
  music.py         background music player (title + one theme per level)
  music/           music loops (WAV), generated by tools/make_music.py
  storage.py       save file
  icon.py          app icon drawn in code
packaging/         PyInstaller + .deb build scripts, Windows version resource, .desktop entry
tools/make_music.py  composes the background music loops
tests/             unittest suite
BUGS.md            fixed bugs and known issues, by version
```

## Changelog

See [BUGS.md](BUGS.md) for fixed bugs and known issues.

### v0.1.3
- Food no longer repeats: each eaten food is replaced by one you haven't had yet (highlighted
  **NEW**); a Classic game never repeats a food, and the menu always has all three kinds.
- More realistic body: smooth anatomical outline with face, ear, ribs, spine and arm; a J-shaped
  stomach instead of a square; coiled small intestine; segmented large intestine.
- Background music that changes every level (5 level themes + a title theme), with a
  **LEVEL UP!** banner, a LEVEL counter in the header, and a Music setting (`N` key).

### v0.1.2
- Burps and farts are now **real recordings** (public-domain CC0 clips from Freesound), one per
  food, replacing the synthesized versions that still sounded electronic.
- Recordings are bundled inside the .exe and .deb; credits in `digestion_lab/sounds/CREDITS.md`.

### v0.1.1
- Realistic burp and fart sounds: rebuilt as physical models (irregular air puffs through throat,
  mouth and body resonances) instead of buzzy tones. Each food still has its own voice.
- Fixed a filter bug that made every burp and fart a low hum.
- Older builds are no longer deleted when a new .exe is built.

### v0.1.0
- First release: Windows .exe and Debian/Ubuntu .deb.
- Classic, Rush and Endless modes; Easy, Normal and Hard difficulty.
- 14 foods with per-food burp and fart sounds, a Food Log and 10 achievements.
- English and Japanese.
